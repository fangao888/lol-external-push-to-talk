# 按键发言工具

Windows 原生托盘程序，使用 Go 调用 Windows Core Audio。默认静音，按住快捷键时解除静音，松开立即恢复静音，适用于绕过英雄联盟自身的按键发言故障。

## 使用

1. 双击本目录的 **按键发言工具.exe**。
2. 选择麦克风，点击 **录入快捷键**（也可点击快捷键显示框），直接按下需要的按键或组合键，再点击“保存并应用”。默认使用 **F8**。支持键盘左上角的 **· / ~ 键**、`V`、`Ctrl+Space`、`Alt+V`、`Mouse4`、`Mouse5`、常见标点和小键盘。可用修饰键为 Ctrl、Alt、Shift；录入修饰键后继续按主键即可。
3. 在英雄联盟中打开语音，设置为**自由发言**，并选择**同一个麦克风**。游戏保持连接，由本工具决定麦克风什么时候实际有声音。
4. 松开快捷键后重新按住说话。红色托盘图标表示静音，绿色表示正在发言，灰色表示暂停，黄色表示异常。

关闭窗口或点击“收起到托盘”后继续工作。左键托盘图标打开设置，右键可暂停或退出。**暂停期间保持静音；点击“退出（恢复麦克风）”正常结束程序时，会自动解除所控麦克风的静音**，之后其他软件可以正常使用麦克风。

## 行为说明

- 每 10ms 通过 `GetAsyncKeyState` 读取一次全局按键状态，按键仍然传给游戏；它不会替你屏蔽游戏原有操作，因此建议避开技能键、聊天键等。实际响应时间受 Windows 调度和音频驱动影响。
- 组合键中的任意一个键松开都会静音。启动、应用设置、暂停恢复、锁屏/休眠恢复、切换或重连设备后，都必须先松开全部相关按键，再按住才能开麦。
- 录入期间保持静音，点击“取消录入”或切换到其他窗口会保留之前的快捷键。录入只识别按键，不依赖输入法产生的字符；配置中的 `OEM_3` 即键盘左上角的 · / ~ 键。
- “跟随 Windows 默认通信麦克风”每秒检查一次默认通信端点。如果游戏固定选择了某个麦克风，建议在工具中也固定选择该设备。
- 所选设备断开时显示异常，不会静默改用另一个录音设备。重新连接后会自动重试，也可点击“刷新麦克风”。
- 这是**系统录音端点静音**，使用该麦克风的 QQ、微信、Discord 和录音软件都会受到影响。不会改变麦克风增益，也不会撤销应用的麦克风访问权限或关闭硬件电源。
- 工具每 100ms 检查一次实际静音状态，并纠正其他程序对该设备静音状态的修改。它不作为硬件隐私开关使用。
- 正常退出会解除所控麦克风的静音，即使启动前已静音也会恢复可用。如果被任务管理器强制结束、系统崩溃等，退出清理无法执行，麦克风可能保留当时的静音状态。
- 如果游戏的语音连接、麦克风权限或采集本身故障，本工具无法修复。游戏及反作弊环境仍需在实际对局中验证；默认使用普通用户权限运行。
- 为避免多个进程争用麦克风，同一 Windows 会话只运行一个实例。

设置与日志保存在当前用户的 `%APPDATA%\MicPTT\`，分别为 `config.json` 与 `app.log`。首次启动不会修改英雄联盟配置，也不会设置开机自启。

## 开发与编译

要求 Windows 10/11，Go 1.25.4 或更高版本。界面采用 Walk 原生 Windows 控件；音频线程独立于界面线程，界面卡顿不会阻止音频线程继续检测松键。

```powershell
# 生成资源、运行测试和静态检查，然后输出单文件 EXE。
powershell -ExecutionPolicy Bypass -File .\build.ps1

# 已有 syso 资源时可以直接编译，不需要 C 编译器。
go build -trimpath -ldflags "-H=windowsgui -s -w" -o 按键发言工具.exe .

# 控制台只读诊断：枚举设备并读取当前静音状态，不接管麦克风。
go run . -diagnose

# 单元测试使用虚拟麦克风和虚拟按键，不改变本机输入或音频状态。
go test ./...
go vet ./...
```

`go generate .` 使用固定版本的 `github.com/akavel/rsrc` 生成 32/64 位 Windows 资源。已提供生成好的 `resources_windows_amd64.syso` 和 `resources_windows_386.syso`，正常构建不必重新下载资源生成工具。

测试覆盖快捷键解析、配置保存、按住/松开、暂停、重叠系统阻止状态、设备切换与拔插恢复，以及正常退出时解除静音、恢复失败时允许重试。可选的界面烟雾测试只创建窗口和托盘，不接管真实麦克风：

```powershell
$env:MICPTT_UI_TEST = '1'
go test -run '^TestNativeSettingsSmoke$' -v
Remove-Item Env:MICPTT_UI_TEST
```
